# Cálculo del total de una compra

**Estudiante:** Jorlady Mendoza

## Descripción

Este proyecto contiene un programa desarrollado en Python que permite calcular el total de una compra.

El programa utiliza una función llamada `calcular_total`, que recibe dos parámetros: el precio del producto y la cantidad comprada. La función multiplica estos valores y devuelve el resultado.

## Ejemplo

- Precio del producto: 10
- Cantidad: 3
- Total de la compra: 30

El resultado se muestra en la consola utilizando `print()`.
